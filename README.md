**Rufix es una herramienta gráfica, parecida a Rufus de Windows, para preparar memorias USB desde EasyOS.**

Te permite:

- **Crear USB arrancables de Linux**, grabando imágenes `.iso`, `.img` o `.raw`, incluidas algunas imágenes comprimidas.
- **Grabar una imagen `.img` de EasyOS en un pendrive**, para después arrancar el ordenador desde él.
- **Preparar un USB de instalación de Windows 10/11**, con opciones específicas para ese sistema.
- **Formatear pendrives y tarjetas SD** en FAT32, exFAT, NTFS, ext4 o FAT16, eligiendo MBR o GPT.
- **Extraer archivos comprimidos a un USB** después de formatearlo.
- **Comprobar la grabación, buscar bloques defectuosos y calcular sumas de comprobación**.

En tu caso, lo más interesante es **crear pendrives de prueba de EasyOS y otras distribuciones sin salir de EasyOS**. Grabar la imagen prepara el USB; no configura una instalación junto a Windows en el disco interno.

La adaptación que  he preparado añade el acceso al menú de EasyOS y corrige su apertura. Algunas funciones necesitan herramientas adicionales instaladas.

**Atención: formatear o grabar una imagen borra los datos de la unidad USB seleccionada.**
